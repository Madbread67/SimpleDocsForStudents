# Шаблоны документов для практики

## Список шаблонов:
1. ХАРАКТЕРИСТИКА.docx - Характеристика студента
2. АТТЕСТАЦИОННЫЙ ЛИСТ.docx - Аттестационный лист
3. ДНЕВНИК.docx - Дневник практики
4. ЛИСТ КОНТРОЛЯ.docx - Лист контроля посещаемости
5. ОТЧЕТ.docx - Отчет по практике
6. ХАРАКТЕРИСТИКА ПРАКТИКАНТА.docx - Характеристика практиканта

## Доступные заполнители:
- {{FIO}} - ФИО студента
- {{Specialnost_id}} - Код специальности
- {{Grupa}} - Группа
- {{Kurs}} - Курс (по умолчанию: 3)
- {{FormaObucheniaOchnaia_or_Zaochnaya}} - Форма обучения (по умолчанию: очная)
- {{Модуль}} - Название модуля
- {{Организация}} - Название организации
- {{Адрес организации}} - Адрес организации
- {{Адрес Практики}} - Адрес места практики
- {{Преподаватель}} - ФИО преподавателя
- {{дата начала практики}} - День начала практики
- {{дата конца практики}} - День окончания практики
- {{практика тип}} - Тип практики (ПП/УП)

## Как редактировать шаблоны:
1. Скопируйте нужные DOCX файлы в эту папку
2. Откройте файлы в Microsoft Word или LibreOffice Writer
3. Вставьте заполнители в нужные места документа
4. Сохраните файлы
5. В приложении нажмите "Редактор шаблонов" -> "Обновить список"

## Важно:
- Не меняйте имена файлов шаблонов
- Сохраняйте файлы в формате .docx
- Заполнители должны быть в двойных фигурных скобках: {{ИМЯ_ПОЛЯ}}
